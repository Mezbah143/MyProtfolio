AI Study & Job Assistant

A practical FastAPI application for turning notes and job descriptions into summaries, skill insights, study plans, and grounded answers.

Back to work

The problem

Students preparing for jobs often switch between notes, job posts, resumes, and scattered preparation tools. This project brings those workflows into one explainable application.

What I built

  • FastAPI endpoints for summarization, skill extraction, plan generation, resume matching, Q&A, and similarity.
  • SQLite history so users can revisit previous results.
  • Input validation and secret-pattern guardrails for safer text handling.
  • Automated tests for health, validation, matching, grounded answers, and guardrails.

What I learned

I practiced API design, structured JSON responses, deterministic AI-style logic, source grounding, semantic similarity, and explaining technical tradeoffs clearly.
